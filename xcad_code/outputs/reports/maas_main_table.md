## 表 0 方法清单（臂=同一超参/同一 seed/按 val MRR 选 checkpoint）

| 名称 | 类型 | 一句话 |
|---|---|---|
| `base` | 学习臂 | 论文配置直接搬到 maas（无任何先验） |
| `hetero` | 学习臂 | 论文配置 + 关系异构消息基（§18 消融） |
| `static` | 学习臂 | 论文配置去掉 GRU 时间演化（§18 消融） |
| `baseemb` | 学习臂 | head 表征 += 可学习的 base 共享嵌入（§21） |
| `basefeat` | 学习臂 | head 表征 += 注入的 base 历史卡型直方图（§22） |
| `baseprior` | 学习臂 | 输出层 += α·log1p(base 历史卡型计数)（§23） |
| `headprior` | 学习臂 | 输出层 += base 与 head 两条先验通道（静态表，§24） |
| `priorgate` | 学习臂 | 双通道 + 按行 softplus 信任门控（静态表，§25） |
| `priorts` | 学习臂 | 双通道 + 时序口径先验表（每快照只用严格更早的边，§26） |
| `priortsgate` | 学习臂 | 时序口径 + 按行信任门控（§26） |
| `priorts_s43` | 学习臂 | priorts 的第二个 seed（只为量 run-to-run 噪声） |
| `tail_prior` | 非学习通道 | 恒定答历史最热卡型（常数） |
| `entity_mem` | 非学习通道 | 背历史：该 head 自己的历史众数卡型（复发通道上界） |
| `base_hist` | 非学习通道 | 父节点历史：base_id 的历史卡型直方图（属性通道） |
| `add_hist` | 非学习通道 | 两表 log1p 直接相加（不学习的合并） |
